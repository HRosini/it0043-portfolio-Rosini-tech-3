# IT0043 Portfolio — Module 3

A four-page student portfolio for VS Code. Open this folder in VS Code, then open `index.html` in a browser (or use the Live Server extension).

## Files
- `index.html`, `about.html`, `skills.html`, `contact.html`: the four portfolio pages.
- `css/style.css`: the shared, AI-assisted starting stylesheet.
- `ai-style.css`: rival stylesheet for comparison. It is not linked by the four site pages.
- `preview-ai/`: a separate copy of the pages linked to the rival stylesheet.
- `output/pdf/M3-comparison.pdf`: stylesheet measurements, contrast ratios, and 320 px observations.
- `M3-decisions.md`: token notes and reasons for accepted/rejected arguments.

The assignment says the first stylesheet should be unaided. This generated project does not meet that authorship condition; use it as a reference and rewrite/retype any CSS you decide to submit as your own work.

## Preview the rival stylesheet
Open `preview-ai/index.html`. The comparison copy links to `preview-ai/ai-style.css`; the main pages continue to link only to `css/style.css`.
